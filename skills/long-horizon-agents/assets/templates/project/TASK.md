# 易懂的任务名称

这是一份可随实际情况修订的任务说明，不是预先合同。仅保留有用字段；约束和额外检查应有具体依据，未知情况不先转为硬门槛。

## 目的和完成判据

- 要回答的问题 / 要交付的结果：待填写。
- 必要输入与依赖：待填写。
- 授权依据与范围：待填写，引用 MISSION 或用户指令。
- 交付物与完成判据：待填写，包含必要后继，避免只完成启动。
- 失败、负结果或无收益时的下一动作：待填写。

## 实际执行

- 负责人及资源所有者：待填写。
- 状态：待填写（READY / RUNNING / WAITING / BLOCKED / COMPLETED / FAILED / STOPPED）。
- 实际工作区、配置与输入入口：待填写。
- 代码版本与运行身份：按实际风险记录；复用稳定证据。
- 启动 / 终态时间与退出状态：待填写。
- 下一动作与依赖信号：待填写。
- 预计终点、估算依据与下次观测：待填写。
- 实际调整及理由：仅在重要变化时记录；注明对恢复、数据或比较的影响。
- 运行日志、资源摘要与成本：引用原位置。

## 结果与接续

- 完整结果和负项：终态后填写。
- 适用范围、缺失与不确定性：待填写。
- 稳定产物、记录接收与可复用路径：待填写。
- 已完成的后继 / 尚未满足的完成判据：待填写。
- 给规划者的建议与证据：有必要时填写。
