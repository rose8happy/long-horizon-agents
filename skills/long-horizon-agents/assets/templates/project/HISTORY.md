# {{PROJECT_NAME}}｜重要任务与结果索引

维护：执行者。记录有复用或决策价值的已闭合任务，链接原证据；不复制完整日志。

值得记录：重要问题的答案、可复用成果、成本较高的工作、信息价值高的失败和负结果、有理由停止的方向。普通轮询和小修复通常不用单列。

下面是条目格式，替换后使用；“完成”“失败”“停止”照实区分。

## 日期｜易懂的任务名称

- 状态与任务卡：待填写。
- 目的：要回答的问题或形成的交付。
- 实际结果：观察到什么，完成了什么。
- 适用范围与局限：哪些解释仍未排除，什么情况下需要重做。
- 可复用内容：代码、数据、方法或已有资格。
- 证据：原任务、结果与稳定产物链接。
- 实际成本：有价值时记录耗时、资源或费用；失败成本照实保留。
- 后续影响：改变了什么决定；有重要决定时链接 `DECISIONS.md`。

按时间追加即可。记录变长后将旧条目归档并保留索引，不要求每轮读取全部历史。新证据可以重新开启旧方向。
